EMON MEGA UNIVERSE — GitHub Pages ZIP
=====================================

এই সাইটে রয়েছে:
- ৬টি ব্রাউজার মিনি গেম: Reaction Rush, Memory Match, Lucky Dice, Rock Paper Scissors, Number Hunt, Challenge Wheel
- কুইজ চ্যালেঞ্জ
- Truth or Dare ও বন্ধুদের নাম থেকে র‍্যান্ডম নির্বাচন
- ব্রাউজারে সংরক্ষিত লোকাল প্রোফাইল, কয়েন ও প্রোগ্রেস
- নামের পোস্টার তৈরি ও PNG ডাউনলোড
- মোবাইল-ফ্রেন্ডলি ডিজাইন ও শেয়ার সুবিধা

GitHub Pages-এ প্রকাশ:
1. ZIP ফাইল Extract করুন।
2. GitHub-এ লগইন করে New repository তৈরি করুন; নাম দিন emon-mega-universe এবং Public রাখুন।
3. Add file > Upload files-এ Extract করা ফোল্ডারের ভেতরের index.html, style.css, script.js এবং README-BN.txt আপলোড করুন। ZIP ফাইলটি সরাসরি আপলোড করলে সাইট চালু হবে না।
4. Commit changes চাপুন।
5. Repository > Settings > Pages খুলুন।
6. Build and deployment-এ Deploy from a branch নির্বাচন করুন।
7. Branch: main এবং folder: /(root) বেছে Save করুন।
8. কয়েক মিনিট অপেক্ষা করুন। Pages পৃষ্ঠায় প্রকাশিত URL দেখাবে।

গুরুত্বপূর্ণ সীমাবদ্ধতা:
- এই ZIP একটি static website; আলাদা সার্ভার/ডেটাবেস ছাড়া চলে।
- প্রোফাইল, কয়েন ও স্কোর শুধু একই ব্রাউজার/ডিভাইসে localStorage-এ রাখা হয়। সবার জন্য একই অনলাইন লিডারবোর্ড, লগইন বা রিয়েল-টাইম multiplayer করতে আলাদা backend দরকার।
- Share API সমর্থন না করলে সাইট লিংক কপি করার চেষ্টা করবে; কিছু ব্রাউজারে clipboard অনুমতি প্রয়োজন হতে পারে।
- Google Fonts অনলাইনে থাকলে বাংলা ফন্ট সুন্দর দেখাবে; না থাকলে সিস্টেমের বিকল্প ফন্ট ব্যবহার হবে।
- এখানে কোনো APK বা অন্যের কপিরাইটযুক্ত গেম ফাইল নেই।
